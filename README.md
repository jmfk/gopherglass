# Gopherglass

*A new window onto the web, with an old internet soul.*

Gopherglass is an early-stage browser project for iOS and macOS, intended to use Apple's system WebKit.

## The name

**Gopherglass** brings together **Gopher** and **Spyglass**: a nod to the early internet and the curiosity of exploring it.

## Status

Project inception. This repository currently contains the project introduction and Git ignore rules. There is no browser implementation or downloadable release yet.

The first prototype will focus on opening a web address and navigating back, forward, and reloading. Tab management, bookmarks, and session restoration can follow once the basic browsing experience works.
